# BlockCode — программирование агента блоками внутри Minecraft

Аналог MakeCode/Code Builder для **Minecraft Java Edition 1.20.1** (Fabric).
Ученик нажимает **C** — прямо в игре открывается редактор: блоки слева, тот же код на Python справа.
Нажимает **▶ Запустить** — редактор закрывается, и агент строит по программе блок за блоком.

## Что внутри прототипа

- **Редактор в игре** на Blockly (движок Scratch и MakeCode) через встроенный браузер MCEF.
  Страница лежит внутри мода, интернет на уроке не нужен.
- **Python рядом с блоками**, обновляется при каждом изменении (только для чтения).
- **Агент** — летающий робот-аллей с подписью «Агент <ник>». У каждого ученика свой.
  Команды: лететь (вперёд/назад/влево/вправо/вверх/вниз), повернуть, поставить блок (26 материалов),
  сломать блок, «видит блок?», лететь ко мне, сказать в чат.
- **Циклы, условия, переменные, функции, математика.**
- **Скорость:** медленно / обычно / быстро / мгновенно. Кнопка **■ Стоп**.
- **Пример «Домик»** — 5×5, стены с дверью и крыша, на функциях, циклах и условиях.
- **Проекты** сохраняются в `.minecraft/config/blockcode/projects/*.json` — их можно собрать или раздать.
  Последняя программа сохраняется автоматически и не пропадает при закрытии редактора.
- **Защита от ошибок:** бесконечный цикл не подвешивает игру, агент не улетает дальше 100 блоков,
  ставит только разрешённые блоки. Ошибки показываются в чате по-русски.

## 1. Собрать мод (один раз)

**Вариант А — без установки чего-либо, через GitHub:**
1. Создайте репозиторий на github.com и загрузите в него эту папку (можно через «Add file → Upload files»).
2. Откройте вкладку **Actions** — сборка запустится сама (2–4 минуты).
3. В завершённой сборке скачайте архив **blockcode-mod** — в нём `blockcode-0.1.0.jar`.

**Вариант Б — на компьютере с интернетом:** нужна Java 17 или новее.
```
gradlew build          (Windows: gradlew.bat build)
```
Готовый мод: `build/libs/blockcode-0.1.0.jar`.

## 2. Установить на компьютеры учеников

Проще всего через **Prism Launcher** (бесплатный, можно настроить один раз и скопировать папку на все ПК):
1. Создать экземпляр: Minecraft **1.20.1**, загрузчик **Fabric**.
2. В «Моды» добавить: **Fabric API**, **MCEF** (версия для Fabric 1.20.1) и файл `blockcode-0.1.0.jar`.
3. Запустить. При первом запуске MCEF сам скачает компонент браузера (~100 МБ, один раз).
   После этого интернет не нужен.

Для общего школьного сервера: положите `blockcode-0.1.0.jar` и Fabric API в папку `mods` сервера
(MCEF на сервер не нужен). У учеников мод ставится как выше.

## 3. На уроке

1. Войти в мир (лучше творческий режим, плоский мир).
2. Нажать **C** → **🏠 Пример: домик** → **▶ Запустить**.
3. Смотреть, как агент строит. Потом менять: материал, размер (числа в циклах), высоту, окна из стекла.
4. Справа видно, как та же программа выглядит на Python — `for этаж in range(1, 5):`, `agent.place(DOWN, OAK_PLANKS)`.

Клавишу можно переназначить в «Настройки → Управление → BlockCode».

## Что проверено, а что нужно проверить в игре

Проверено: интерпретатор агента (тесты в `src/test`: домик строится ровно 5×5 с дверью и крышей,
бесконечный цикл и бесконечная рекурсия останавливаются), а также что блоки примера «Домик»
превращаются ровно в ту программу, которую проверяют тесты.

Сборку в игре мы не запускали (в среде разработки не было доступа к репозиториям Minecraft).
Если `gradlew build` сообщит, что не найдена версия **MCEF**, откройте https://modrinth.com/mod/mcef/versions,
посмотрите номер для Fabric 1.20.1 и впишите его в `gradle.properties` → `mcef_version`.

## Ограничения прототипа и что дальше

- Python только для чтения; правка текста → блоки — следующий этап.
- Агент ставит блоки «бесконечно», без инвентаря (как в творческом режиме).
- Нет дверей, лестниц и поворота брёвен — добавляются отдельными блоками.
- Функции без параметров.

## Устройство

| Часть | Файлы |
|---|---|
| Редактор (Blockly, Python, проекты) | `src/main/resources/assets/blockcode/editor/` |
| Экран редактора в игре, клавиша C, мост страница → игра | `src/main/java/ru/blockcode/client/` |
| Интерпретатор программы (без зависимостей от Minecraft) | `src/main/java/ru/blockcode/program/` |
| Агент в мире, выполнение по тикам, пакеты | `src/main/java/ru/blockcode/*.java` |

Список разрешённых блоков: `AllowedBlocks.java` и `BLOCK_CHOICES` в `editor/blocks.js` — менять оба.
